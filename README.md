### About

I did a year of computer science before dropping out to go all in on AI/ML, teaching myself project by project instead of sitting through more lectures. I like taking things apart to understand exactly how they work, then building my own version instead of relying on someone else's black box. I'm particular about the details, if something's sloppy I'll notice, and I'll fix it before I call it done.

### Currently building

**[fflags-tracker](https://github.com/adezdev/fflags-tracker)**
A local-first Roblox FastFlag tracker. Browse, diff, and get notified when flags change, across 13 platforms.
Built with TypeScript, Next.js, Drizzle ORM, and SQLite. Self-hosted, MIT licensed.
